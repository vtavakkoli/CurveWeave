# Code of Conduct

CurveWeave contributors are expected to keep project spaces respectful, technical and constructive.

Be considerate of differing experience levels and backgrounds. Critique code and ideas rather than people. Avoid harassment, personal attacks, discriminatory language, deliberate disruption, and disclosure of private information.

Maintainers may edit or remove contributions that violate these expectations and may restrict participation when necessary to keep the project safe and productive.

If a conduct issue requires private handling, contact the repository owner through an appropriate private GitHub channel rather than escalating it publicly.
